## 核心项目

| 项目 | 简介 |
| --- | --- |
| [**rgpui**](https://github.com/launcher-rs/rgpui) | 自研 Rust 原生 GUI 框架，组织内多数桌面应用的底层 |
| [**rupix · 拾景**](https://github.com/launcher-rs/rupix) | 轻量级跨平台截图工具：托盘常驻、全局热键、截完即存即复制，支持矢量标注、取色与离线 OCR |
| [**rumark · 拾墨**](https://github.com/launcher-rs/rumark) | 块式 Markdown 编辑器：所见即所得与源码双模式，支持 HTML / PDF / Word 导出与中文排版 |
| [**ruterm**](https://github.com/launcher-rs/ruterm) | 远程连接工具：集成 SSH、本地终端、SFTP、Telnet 与 RDP / VNC 远程桌面 |
| [**audio-cpp-rs**](https://github.com/launcher-rs/audio-cpp-rs) | 基于 ggml 的本地音频推理引擎 audio.cpp 的 Rust 安全绑定：TTS / ASR / VAD / 声音克隆 / 音源分离等，覆盖 135 个模型族，支持 CPU / CUDA / Vulkan / Metal 等后端 |
| [**mermaid-renderer**](https://github.com/launcher-rs/mermaid-renderer) | 纯 Rust 的 Mermaid 图表渲染库，直接输出 SVG，不依赖浏览器与 Node.js |

## 生态与基础库

- **rgpui 生态**：[rgpui-component](https://github.com/launcher-rs/rgpui-component)、[rgpui-term](https://github.com/launcher-rs/rgpui-term)、[scenekit](https://github.com/launcher-rs/scenekit) 等围绕框架的组件与实验
- **启动器插件**：[launcher-plugin](https://github.com/launcher-rs/launcher-plugin)（Flow Launcher 插件 Rust 开发库）与 [launcher-plugin-template](https://github.com/launcher-rs/launcher-plugin-template)（快速上手模板）
- **工具与实验**：[crawlkit](https://github.com/launcher-rs/crawlkit)、[firecrawl2](https://github.com/launcher-rs/firecrawl2)、[tavily-rs](https://github.com/launcher-rs/tavily-rs)、[youdao-translate](https://github.com/launcher-rs/youdao-translate) 等
